논문 실험은 반드시 윤리적으로 수행해야 함. 대충 진행하거나 결과를 부풀리는 것 절대 금지.

**Why:** 이건 실제 학술 논문이고, 사용자가 "윤리적이어야 해", "다른 논문에서 보고된 것들과 완전 동일하게"라고 강조.

**How to apply:**
- 평가 메트릭은 관련 논문(SRC, LPReKL, GenMentor 등)에서 사용하는 것과 동일하게
- Baseline 구현은 원 논문 기준으로 공정하게
- 불공정한 비교 절대 금지 (다른 pool, 다른 KC set 등)
- 결과가 안 좋으면 솔직하게 보고, 숨기지 말 것
- 모든 실험은 재현 가능하도록
